### 🗂️ Summary

#### 🔹 Stack Memory
Used for primitive data types: Number, String, Boolean, null, undefined, Symbol, BigInt

Stored by value

Memory is fixed and managed automatically

Fast access


#### 🔸 Heap Memory

Used for non-primitive data types: Object, Array, Function

Stored by reference

Allocated dynamically

Slower access compared to stack
